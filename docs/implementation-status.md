Updated 29 October 2026 (Malaysia time).

- The final pinned PostgreSQL 18.6, Redis 8.10.3 and Nginx 1.30.6 images are running; all seven services report healthy or running. Nginx resolves the frontend through Docker DNS after container recreation.
- Django health-only scaffold boots, connects to PostgreSQL and returns `domain_api: not_implemented`. `manage.py check` and migrations check passed.
- All ten frontend routes, common shell, deterministic seed, local map, inspectors, stage controls, zone rule, copilot intents and portal interactions are implemented. The one-click five-minute runner advances the six scenes without discarding incidents, approvals or audit history; manual scene jumps remain fixed-seed resets.
- Chrome rendered the local MapLibre map. The browser console hydration mismatch discovered during review was fixed. A simpler fallback appears if MapLibre cannot load in a browser environment.

Landing, control and group screenshots were reviewed in both themes at presentation size; the 3D inset can be hidden. One switch in each header saves the theme and updates the map palette.
- Map polish now includes vessel heading and docking guides, tug and mooring cues, crane lift animation, hatching for active exclusion zones, critical alert marker and toast, entity hover details, expanded search, and a local canvas FPS readout. Standard demo roles see worker zones on the map.
- The Control map now shows a 2D preview built from the simulated vessels, 400 occupied storage slots, cranes and vehicle routes as soon as the page becomes interactive while MapLibre and Three.js initialize. It remains available when WebGL cannot start or its context is lost; the yard shortcut and entity search still work. - The map renders 2,000 container records across four labeled storage yards and carried loads. Stored 20-foot and 40-foot units use correctly proportioned five-tier instanced stacks. Vehicles use perimeter and inter-yard roads, and a sampled route test verifies model clearance from every stored container on the base and approved recovery routes. Loaded truck and AGV models carry a linked 40-foot container drawn to the trailer dimensions; empty models show bare platforms. Clicking a vehicle opens its own status plus the carried container's ID, size, vessel and origin slot, with a link to the container record. Moving containers are absent from storage stacks and resolve to their carrier on map search.

The inspector shows the current simulated fix for the supervisor role and retains zone-only location privacy for standard demo roles. The scripted Crane 3 breach still holds the worker at its incident position until the approved safe-lane route moves it back to a walkway.

Road beds and vehicle click targets match the larger trucks. Compact windows open near a truck and the stacks; the yard shortcut moves closer still. ## Still being verified or limited

- The stage scenes are deterministic and have motion cues, but the detailed terminal geometry remains illustrative rather than a physical digital twin. Container, vehicle and worker shapes and GPS fixes are procedural simulations, not measured CAD assets or live telemetry.
- The ten portal UI routes are functional simulation views, but the future `PortDataSource` adapter is not yet wired to hydrate all pages in API mode. API mode deliberately reports unavailable instead of showing demo values.
- No actual Django identity/domain endpoints, persistence of operational records, real AI, TOS, AIS, equipment telematics or Maritime Single Window integration exists. No real source-system contracts have been supplied yet.
- Worker redaction and shipping-line scope in simulation are client-only demonstrations. Production enforcement requires Django.
- The browser suite observed no external runtime requests across all ten portals. A physical internet-disconnect rehearsal remains outstanding. The earlier 59–60 FPS desktop Chrome sample predates the new 3D map layer. The current software-rendered container capture fluctuated between roughly 3 and 18 map canvas FPS during review, which cannot certify GPU performance. Measure sustained FPS on the actual presenting laptop and projector at 1920×1080; reduce the optional inset if needed. The browser recording predates the new map objects, has no narration and should be regenerated and viewed before stage use.
